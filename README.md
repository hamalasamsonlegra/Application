# Application

This repository now contains a real installable React app scaffold built with Vite.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   npm start
   ```
3. Open the app in your browser:
   ```bash
   http://localhost:3000
   ```

## Scripts

- `npm install` — install dependencies
- `npm start` — run the development server
- `npm run build` — build for production
- `npm run preview` — preview the production build

## Stack

- React
- Vite
- JavaScript
